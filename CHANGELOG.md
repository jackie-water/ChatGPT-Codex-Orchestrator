# Changelog

## v0.1.0 — release preparation

### English

This release-preparation entry records the existing capabilities: an isolated installer/Sandbox workflow; explicit-route-v1 callbacks; immutable reports; exact-SHA review and human approval; truthful status, doctor, and repair diagnostics; and MIT licensing.

Operating limits: Windows v0.1 support; authenticated browser/CLI and human authorization dependencies; UI delivery can require repair; and ambiguous delivery must not be blindly resent. Legal files such as LICENSE may still require explicit review evidence under the existing path classifier; not all documentation automatically skips review.

Publication is pending. This entry does not provide publication evidence or mark old roadmap/E2E checklists complete.

### 简体中文

本条目用于发布准备，记录现有能力：隔离的 installer/Sandbox 流程、explicit-route-v1 回调、不可变报告、精确 SHA 审查与人工批准、真实的 status/doctor/repair 诊断，以及 MIT 许可。

运行限制：支持 Windows v0.1；依赖已认证的浏览器/CLI 和人工授权；界面投递可能需要修复；投递结果不明确时不得盲目重发。根据现有路径分类器，LICENSE 等法律文件仍可能需要明确的审查证据；并非所有文档都会自动跳过审查。

公开发布尚待完成。本条目不提供发布证据，也不表示旧的路线图或 E2E 清单已完成。
